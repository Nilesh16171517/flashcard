# RecallForge — Flashcard Study App

RecallForge is a web-based **flashcard app** built for active recall and organized studying.

## Features

- Flashcards for study and revision
- Image occlusion for visual memorization
- Drawing and pen annotations
- Text annotations and editable text boxes
- Topic and subtopic organization
- Study navigation with next/previous cards
- Active-recall reveal controls
- Google account authentication
- Private Google Drive data storage
- Responsive web interface
